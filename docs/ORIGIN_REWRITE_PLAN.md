# Origin 重写方案

## 目标

词源用于记忆，不用于堆砌未经核实的词典碎片。全部单词都经过同一个结构化生成器，再由少量人工校订覆盖高价值或易错词。

## 展示顺序

1. **可理解的词根组合最优先**：不论组合发生在现代英语、法语还是拉丁语阶段，只要拆开后能帮助理解，就先展示各部分及其中文义。
2. **现代构词其次**：能直接拆成英语前缀、词干、后缀或复合词时，解释各部分。
3. **记忆连接**：用一句中文串起“组成部分 → 早期图景 → GRE 词义”。
4. **历史路径最后**：只保留 2–4 个可信语言节点，不强迫每个词追到拉丁语或希腊语。
5. **完整来源外链**：需要考据时再打开 Etymonline。

## 数据清洗

- 不再显示统一的“原始义”字段；只有人工校订并有中文解释时，才把早期意义写进节点。
- 删除抓取残片，如 `used`、`from Greek`、`sense of`、孤立的 `not` / `to`。
- 不用现代释义冒充原始义。
- 没有可靠历史链时，只展示现代词形、GRE 语境义与同义词联系。

## 人工校订示例

- `undergird = under + gird`：从下面束紧、托住，引申为“支撑”。
- `surreptitious = sub- + rapere`：在下面/暗中 + 抓走；`sub-` 在 `r` 前同化为 `sur-/surr-`，由“暗中抓走”连接到“秘密的”。
- `faithful = faith + -ful`：具有信实、可靠的性质；“accurate, reliable”是现代语境义，不是拉丁语原始义。
- `discernment = discern + -ment`：辨别的能力或结果，引申为“洞察力、判断力”。

## 完整性标准

- 990 张卡全部通过新生成器。
- 页面不再直接渲染旧的 `origin` 文本。
- 人工覆盖优先于自动规则；后续可逐词增加覆盖，不需改 UI。
