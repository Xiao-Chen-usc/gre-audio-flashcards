# 词表页与复习模式

## 学习与复习
- 学新词：按原书顺序，同义词对相邻；一对里任意一张点“还不熟”，这一对进不熟库。
- 复习不熟词：优先挑最近点过“还不熟”的对（没有时间记录的旧数据排最后，按原书顺序），整对入选，本轮打乱顺序。答对的卡回到“已掌握”。
- 复习已掌握：每次抽 20 张，从最久没复习的已掌握对里取（没有时间记录的旧数据视为最早），打乱顺序。点“记住了”只更新复习时间；点“还不熟”整对放回不熟库。
- 不显示到期数量，不做固定间隔。

## 词表页 `/gre/#words`
- 放在首页里用 hash 切换，而不是独立路由：线上部署只预渲染 `/gre` 这一个页面（见个人网站仓库的 `deploy.sh`），独立路由在静态 nginx 上会 404。
- 三种状态：已掌握（`known`）、正在学习（`hard`）、还未学到。
- 掌握地图：每格一张卡，每列是原书一页，点一列跳到那一页。
- 列表按页分组，可按状态筛选；默认遮住中文，点一下显示。
- 已掌握的对可以一键放回不熟库（整对）。

## 数据与向后兼容
- `gre-voice-memory-v1` 格式不变。
- 复习时间单独存 `gre-voice-history-v1`：`{ [pairKey]: { seen?, hardAt? } }`。旧版本只重写 v1 键，不会覆盖它。
- 导出文件保留 `learnedWords / reviewWords`，另带可选的 `history`；旧版本导入时忽略它，新版本也能导入旧文件。
